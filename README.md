## 📖 Sobre o Projeto

Este projeto foi criado com o objetivo de modernizar processos, cortar custos e promover a sustentabilidade nas indústrias com o uso a energia solar.

Utilizando um site desenvolvido em HTML e CSS, procuro incentivar grandes indústrias a adotarem a energia solar sustentável, destacando seus benefícios econômicos e ambientais.

## 🎯 Objetivos

- Informar sobre as vantagens econômicas da energia solar.
- Destacar os benefícios ambientais do uso de energia sustentável.
- Incentivar empresas a adotarem fontes de energia renovável
- Apresentar dados e informações sobre sustentabilidade.
